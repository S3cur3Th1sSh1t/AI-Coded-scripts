- 🔐 **LDAP Security**: Channel binding and LDAP signing support (like Certipy)
- 🌐 **SOCKS Compatible**: Works through ntlmrelayx SOCKS5 where other tools fail
- 📊 **Multiple Formats**: BloodHound Legacy v5, CE v6, and BOFHound

### 🔬 payloadfunc-Finder.py
**DLL Function Call Tracer**

> *Which DLL functions does that binary actually call? Now you know.* 🧬

A Windows debugger that attaches to a process (or spawns one), sets INT3 breakpoints on every exported function of a target DLL, and reports the first 5 unique functions called along with their first 4 register parameters (x64 calling convention: RCX, RDX, R8, R9). Times out after 20 seconds if fewer than 3 functions are detected. Useful for reversing, malware analysis, and payload research.

**Features:**
- 🎯 Attach to running PID or spawn a new process
- 🔩 Parses PE export directory in-memory (no disk reads)
